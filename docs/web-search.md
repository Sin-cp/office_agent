# 联网聊天：搜索与网页阅读

输入框的“联网”开关默认开启，允许系统自动判断是否查询。问候、常识或润色已有文字不需要搜索；天气、近期资讯、明确搜索请求及网页链接可触发搜索或网页阅读。关闭开关后，本轮不会调用 Search / Fetch；开关偏好保存在浏览器本地。

每轮提供当前日期、时间与时区，默认 `Asia/Shanghai`。没有可靠的当天数据时，应说明无法核实，不能把模型记忆或旧消息中的来源当作本次查询结果。天气查询应核对地点、日期及更新时间。

查询过程会显示“正在搜索”“正在读取网页”“正在整理回答”，使用已有停止按钮取消。回答下方的“查询来源”区分搜索摘要和网页正文，链接打开新页面，并显示查询时间。来源与消息一同持久化，刷新或继续项目后仍可查看；旧消息不要求包含来源。

附件问答和修改仍沿用原有流程；只有用户明确要求联网补充或核实文档时，才将网页资料带入文档处理。搜索失败会返回说明，停止依赖搜索的文档修改。

## 配置

默认使用官方 DeepSeek Search / Fetch API，与聊天共用 `DEEPSEEK_API_KEY`。不需要修改已有密钥。可选环境变量：

| 变量 | 默认及用途 |
| --- | --- |
| `DEEPSEEK_WEB_BASE_URL` | `https://api.deepseek.com`，管理员配置的搜索服务地址，与模型地址独立 |
| `DEEPSEEK_WEB_API_KEY` | 留空时使用 `DEEPSEEK_API_KEY` |
| `OFFICE_AGENT_TIMEZONE` | `Asia/Shanghai`，无效或系统缺少时区数据时回退到北京时间 UTC+8 |

本地启动从根目录 `.env` 读取配置；Compose 也传递这些变量。密钥仅留在后端，不应设置为 `VITE_` 环境变量。更新后需要重启后端、重建前端；线上发布另行执行。

接口依据：[DeepSeek Search & Fetch 官方文档](https://api-docs.deepseek.com/guides/search/)。搜索和网页读取按供应商规则产生额外费用。

## 接口与边界

`POST /api/tasks` 新增可选 `web_enabled: boolean`，默认 `true`。任务轮询响应新增 `web_activity`（当前查询进度）及 `web_metrics`（工具名、状态、耗时，不保存密钥或查询全文）。

结果新增：

- `web_status`：`disabled`、`not_needed`、`completed`、`partial` 或 `failed`。
- `web_sources`：`title`、`url`、`published_at`、`retrieved_at`、`kind`（`search` / `page`）。
- `web_notices`：结构化的错误或限制说明，含 `code` 和 `message`。

`completed` 代表实际取得了资料，不保证资料本身必然最新。部分网页不可读时可使用已取得的搜索摘要，界面明确标注摘要，并展示读取失败说明。完全失败时返回确定的失败说明，不让模型继续生成未经核实的实时回答。

每轮最多 3 次搜索、5 次网页读取，每次搜索最多 5 个结果。Search / Fetch 单次请求超时 20 秒；DNS 校验最多等待 5 秒。单页最多给模型 10,000 字符，全部网页正文和摘要合计最多 45,000 字符，截断在上下文中明确标记。模型调用继续使用每轮最多 20 次的预算。

搜索服务只收到必要的关键词；网页读取只发送 URL。不发送整份附件、完整会话或客户端 IP。网页内容不参与后续工具计划，不能发起额外请求或修改授权。文档及网页都作为不可信资料处理，不执行其中的指令。

只允许公开 HTTP/HTTPS 地址及标准端口；拦截本机、内网、带用户名密码、非公开 DNS 结果及其他协议。应用不直接抓取网站，Fetch 由 DeepSeek 服务执行，其下游重定向由供应商安全策略控制；返回最终 URL 时也进行校验。调用 Search / Fetch 的 HTTP 客户端不跟随重定向。该功能不包含登录、点击或填写网页表单。

## 验证

自动化测试不访问网络，覆盖关闭开关、来源保存恢复、工具次数限制、超时、空结果、恶意地址、DNS 指向内网、网页指令隔离和取消查询。

真实服务验证使用预设的问候、北京天气、公开文档链接和关闭联网场景，不读取用户项目或附件：

```bash
backend/.venv/bin/python backend/evaluate_web.py --live --output /tmp/office-agent-web-evaluation.json
```

必须显式使用 `--live`，会调用已配置服务并产生用量。报告保存实际回答、来源、查询次数及模型和工具耗时，便于检查是否确实联网及是否使用过期资料。
